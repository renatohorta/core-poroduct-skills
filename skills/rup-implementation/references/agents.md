# rup-implementation — agents and artifacts

> RUP discipline: **Implementation** (discipline 5/9).
> Phase focus: Elaboration → Construction.

| Agent | Base RUP role | Artifacts |
|-------|---------------|-----------|
| `system-integrator` | System Integrator | Integration Build Plan, Build |
| `implementer` | Implementer | Implementation Elements, Implementation Subsystems, Developer Tests, Test Stubs & Testability Elements |

## Missions

### `system-integrator`

- **Mission**: Plan and execute the incremental software integration strategy, avoiding late big-bang integrations.
- **Produces**: Integration Build Plan, Build

### `implementer`

- **Mission**: Write source code, build binaries, compile, generate components and run unit tests.
- **Produces**: Implementation Elements, Implementation Subsystems, Developer Tests, Test Stubs & Testability Elements
