# rup-requirements — agents and artifacts

> RUP discipline: **Requirements** (discipline 3/9).
> Phase focus: Inception → Elaboration.

| Agent | Base RUP role | Artifacts |
|-------|---------------|-----------|
| `system-analyst` | System Analyst | Stakeholder Requests, Vision Document, Use-Case Model Survey, System Actors, Glossary, Requirements Management Plan |
| `requirements-specifier` | Requirements Specifier | Use Cases, Use-Case Packages, Supplementary Specifications (FURPS), Software Requirements Specification (SRS), Requirements Attributes |

## Missions

### `system-analyst`

- **Mission**: Elicit and structure stakeholders' needs, delimit the system boundary and define the functional vision and high-level attributes.
- **Produces**: Stakeholder Requests, Vision Document, Use-Case Model Survey, System Actors, Glossary, Requirements Management Plan

### `requirements-specifier`

- **Mission**: Detail the behavioral specifications of the use cases and the supplementary quality specifications of the system.
- **Produces**: Use Cases, Use-Case Packages, Supplementary Specifications (FURPS), Software Requirements Specification (SRS), Requirements Attributes
