# rup-ccm — agents and artifacts

> RUP discipline: **Configuration & Change Management** (discipline 7/9).
> Phase focus: All phases.

| Agent | Base RUP role | Artifacts |
|-------|---------------|-----------|
| `configuration-manager` | Configuration Manager | Configuration Management Plan, Baselines |
| `change-control-manager` | Change Control Manager (Change Control Board) | Change Request (CR) |

## Missions

### `configuration-manager`

- **Mission**: Structure repositories, manage isolated developer workspaces, and audit and establish the project's formal baselines.
- **Produces**: Configuration Management Plan, Baselines

### `change-control-manager`

- **Mission**: Assess the technical and economic impact of modifications, manage the approval flow and prevent uncontrolled change propagation.
- **Produces**: Change Request (CR)
